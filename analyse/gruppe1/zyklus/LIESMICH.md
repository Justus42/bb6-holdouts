# Werkzeuge zum Bericht analyse/gruppe1_zyklus.md

- `canon.py` Band → Token (t, n); `automat.py` Phasen-Automat (`step`, `rand2`); `zyklus.py` Zyklusfunktion.
- `zyklus_liste.py` je Zyklusanfang eine Zeile (aus Listen von `zweitpruefung.c`); `ZYK_FEHLER=n1|fress|j` = Negativkontrolle.
- `zyklus2.c` zweites, unabhängiges Programm (C); gleiche Ausgabe, gleiche Negativkontrollen.
- `snap.py`, `test_automat.py`, `dump_left.py` Phasen-Schnappschüsse, Regelzählung, nicht erklärte Phasen.
- `check_rand2.py` Randschritte einzeln; `check_rand.py` die ältere, verworfene Fassung (Marke ganz links).
- `gerade.py`, `gerade2.py` Frage „alle Listenelemente gerade“; `nf_check.py` Normalform-Kandidat (scheitert 16-mal).
- `pairs.py`, `blk.py`, `trace.py` Hilfen (Listenzeilen lesen, Bits rekonstruieren, Tabelle).
- `ergebnisse/` Ausgaben bis 10^9 für A, C, D.
